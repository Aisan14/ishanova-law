# Юридическая консультация Ищановой Лязат Маратовны

Адаптивный двуязычный статический сайт (русский / қазақша), без сборщика и внешних библиотек. Откройте `index.html` локально или загрузите содержимое проекта на статический хостинг.

## Перед публикацией

1. Замените `https://example.com` в `robots.txt` и `sitemap.xml` на основной домен.
2. Проверьте юридические тексты `privacy.html` и `consent.html` по фактическому процессу обработки данных и требованиям Казахстана.
3. Подтвердите сведения профиля, телефон, Instagram и формулировку опыта.
4. Если нужен сбор обращений на сервер, подключите согласованный защищённый endpoint; сейчас форма не сохраняет данные и открывает подготовленное сообщение WhatsApp.
5. Счётчики аналитики и рекламные пиксели не подключены. Перед запуском рекламы добавьте утверждённые идентификаторы и обновите политику.

## Страницы

- `index.html` — главная и разделы «Обо мне», услуги, практика, отзывы, контакты.
- `privacy.html` — политика конфиденциальности.
- `consent.html` — согласие на обработку персональных данных.

Для обновления контента редактируйте `index.html` и объект переводов в `script.js`; визуальные стили находятся в `styles.css`.
